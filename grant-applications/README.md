## How to Submit

### Celo Climate Collective
1. Review and customize [celo-climate-collective.md](./celo-climate-collective.md)
2. Visit [celo.org/climate](https://celo.org/climate)
3. Click "Apply for a Grant"
4. Use this document as your source material for the online form
