## How to Submit the Celo Climate Collective Application
1. Review and finalize [celo-climate-collective.md](./celo-climate-collective.md)
2. Add the Celo Alfajores testnet deployment addresses once deployed
3. Visit [celo.org/climate](https://celo.org/climate) and click "Apply for a Grant"
4. Use this document as source material for the online form

## Prerequisites for Gitcoin GG25
1. Deploy all 4 contracts to Celo Alfajores testnet
2. Verify contracts on [Celoscan](https://alfajores.celoscan.io)
3. Create project profile on Gitcoin Explorer
4. Minimum 10 unique contributors for quadratic matching eligibility

## Grant Writing Notes

When writing applications for WeSolar, emphasize:
1. **501(c)(3) nonprofit status (EIN: 92-1042348)** — required for EPA/DOE programs
2. **Environmental justice framing** — low-income, Black, and Latino communities as primary beneficiaries
3. **Open-source commitment** — all code is MIT licensed and publicly available on GitHub
4. **Measurable impact metrics** — households served, kWh generated, CO₂ offset, energy bill reduction %
5. **Celo alignment** — carbon-negative blockchain, mobile-first, Global South accessibility
6. **Pilot-ready** — 3 specific pilot installation sites identified in Year 1 plan
7. **No credit checks** — open access model that excludes no one
